Changelog
=========

0.1.0 (unreleased)
-------------------

* Initial release.
* Iterative solver for coupled electromagnetic–thermal–hydraulic physics.
* Support for INSERT, BITTERS and SUPRAS magnet types.
* Heat-transfer correlations: Montgomery, Dittus-Boelert, Colburn, Silverberg.
* Water-cooling simulation with pressure-drop calculations.
* MPI parallel execution via Feel++.
* Parametric-study automation (``python_magnetworkflows_run``).
* Multi-step commissioning workflows (``commissioning`` module).
